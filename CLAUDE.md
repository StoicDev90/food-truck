# Project Guidelines: Food Truck Web Application

## Tech Stack
- **Framework:** Next.js 16.4.5 (App Router, Server Actions, Server Components).
- **Styling & UI:** Tailwind CSS, shadcn/ui.
- **Database & Auth:** Supabase (PostgreSQL, Row Level Security enabled).
- **Testing:** Vitest + React Testing Library (Vite ecosystem).
- **Deployment:** Vercel.

## Core Roles & Orchestration Pattern
- **Claude (Orchestrator, Planner & Auditor):**
  - Architect solutions, write specifications, construct execution plans, and review code.
  - **Do NOT** write massive code boilerplate directly when sub-agents are available.
  - Audit all code generated by Codex sub-agents for security, strict typing, and test coverage before committing.
- **Codex Sub-Agent (Tactical Executor):**
  - Invoked via MCP runner to execute code blocks, refactorings, and boilerplate defined in the plan.

## Active Plugins & Execution Harness Rules
1. **`superpowers@superpowers-dev` (SDD + TDD Workflow):**
   - **Spec-First:** Never write functional code without defining/updating the feature spec first (`docs/specs/`).
   - **TDD Cycle (Vitest):** Write unit/integration tests first (**Red**), implement minimum working code (**Green**), then refactor (**Refactor**).
2. **`caveman@caveman` (Token Optimization):**
   - Keep chat responses ultra-concise, technical, and direct. Avoid conversational fluff or conversational openers.
3. **`security-guidance@claude-plugins-official` & `code-review@claude-plugins-official`:**
   - Enforce static security checks and code reviews prior to finalizing tasks.

## UI/UX & Design Guidelines
- Utilize **`web-design-guidelines`**, **`ui-ux-pro-max-skill`**, and **`taste`** guidelines for all frontend work:
  - Enforce clean, accessible, and responsive layouts tailored for mobile customers and desktop admins.
  - Prefer subtle micro-interactions, cohesive typography, and shadcn/ui primitives.

## Security & Database Rules
- **Mandatory RLS:** Every new Supabase table must have strict Row Level Security (RLS) policies configured.
- **Server-Side Safety:** Stock modifications, price edits, and order creation must run exclusively inside protected Server Actions or Server Endpoints.
- **Types:** Always auto-generate Supabase TypeScript types after schema changes:
  ```bash
  npx supabase gen types typescript --local > types/supabase.ts
